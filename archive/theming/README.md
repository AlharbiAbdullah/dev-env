# Theming (archived 2026-10-04)

The custom theme system, retired for stock Omarchy themes and wallpapers.

| Path | What it was |
|---|---|
| `themes/` | `theme.lua` sources (calma-dark, calma-light), editor theme generator, comfort scorer |
| `wallpaper/` | wallpaper scorer and the wallpaper standard |
| `wallpapers/` | the calma wallpapers and family art (untracked, Syncthing only) |
| `linux/` | `theme` switcher, `theme-render`, the `rai-theme-set` hook, the OpenCode theme-sync plugin and themes |

The Mac side (`mac/bin/theme`, `theme-extras`, Hammerspoon chooser) stays in `mac/` until the Mac is sold.
